# 🏃 RaceDay - Event Management System

## Part 1: System Planning & Database

### 📋 Project Overview
RaceDay is a full-stack event management system for South African road running, walking, and cycling events. This is Part 1 - the planning phase.

### 📁 Documents
- **[ERD Diagram](docs/ERD.png)** - Entity Relationship Diagram
- **[API Endpoint Plan](docs/API_Endpoint_Plan.md)** - Complete API specifications
- **[SQL Database Script](docs/RaceDay_Schema.sql)** - Full database creation script

### 🗄️ Database Design
The database consists of **5 core entities**:
- **Users** - Organisers and Participants
- **Events** - Race/event details
- **Categories** - Event categories
- **Enrolments** - Participant registrations
- **Results** - Performance results

### 🛠️ Setup Instructions
1. Clone this repository
2. Open `docs/RaceDay_Schema.sql` in SQL Server Management Studio
3. Execute the script to create the RaceDayDB databas
